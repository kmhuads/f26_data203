# HW5B: Public Libraries and Census Demographics in Washington DC


This assignment provides exposure to exploratory analysis of Washington, DC public libraries by integrating **census tract geometry** data with library point coordinates using **GeoPandas**, visualization via **PyGris**, and demographic analysis from the **SVI dataset**. The primary objective is to determine explore census tract themes of public library system in DC.

Major assignment components include:

*   Geospatial intersection to map library coordinates onto census polygons;
*   Merging SVI demographic data with library geometry and tract IDs (`FIPS`/`GEOID`) for regional analysis of tract-level public library demographics (Area/Sq Mi, Total Pop).
